# Политика конфиденциальности Yandex Music Presence

**Дата вступления в силу:** 22 ноября 2026 года

Yandex Music Presence («Приложение») — независимое Android-приложение для отображения названия текущего трека из Яндекс Музыки в статусе Discord Rich Presence. Оно не является официальным продуктом Яндекса или Discord.

## 1. Какие сведения обрабатывает Приложение

Для работы с музыкальными медиасессиями Android Приложение просит отдельное согласие пользователя и системный доступ к уведомлениям (Notification Listener). Такой доступ технически может позволять получать уведомления других приложений, но текущий код использует сведения о пакетах приложений только для поиска медиасессии Яндекс Музыки (`ru.yandex.music`) и не читает текст сообщений, SMS или коды подтверждения.

Из медиасессии Яндекс Музыки Приложение обрабатывает название трека, исполнителя, альбом, состояние воспроизведения, продолжительность/позицию и, если доступно, изображение обложки и музыкальные ссылки.

## 2. Куда передаются данные

- **Discord.** Только когда пользователь включил синхронизацию, данные о текущем треке (например, название, исполнитель, время начала и, при наличии, публичная обложка и ссылка) передаются через Discord Social SDK в Discord. Статус может быть виден другим пользователям Discord. Обработка сведений на стороне Discord определяется его собственными правилами и политикой конфиденциальности: https://discord.com/privacy.
- **Яндекс Музыка.** При включённой синхронизации Приложение может отправлять название текущего трека и имя исполнителя на `https://api.music.yandex.net/search` для поиска подходящей обложки и прямой ссылки. Запрос не содержит пароль или токен учётной записи пользователя. Обработка запроса сервисом Яндекса регулируется его собственными правилами.
- **GitHub.** Для проверки обновлений Приложение запрашивает общедоступный файл `latest.json` по HTTPS. APK скачивается с GitHub Releases **только после нажатия пользователем кнопки установки**. GitHub и сетевые провайдеры могут обрабатывать обычные технические сведения соединения, включая IP-адрес, в соответствии со своими правилами: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.

Разработчик не управляет хранением и обработкой данных указанными сторонними сервисами.

## 3. Что хранится на устройстве

В локальных настройках Android могут храниться согласие на чтение медиасессий, переключатели синхронизации, Discord Application ID, адрес источника обновлений и время последней проверки обновлений. При необходимости APK обновления временно сохраняется в кэше устройства.

Приложение не содержит собственной учётной записи, рекламной аналитики, собственного сервера для сбора персональных данных или базы истории прослушиваний. Для работы Приложения не требуется вводить пароль от Discord или Яндекс Музыки.

## 4. Управление данными и согласие

Пользователь может отключить передачу статуса и нажать кнопку **«Отозвать согласие и остановить синхронизацию»**. Системный доступ к уведомлениям можно отдельно отключить в настройках Android. Для удаления локальных настроек можно очистить данные приложения либо удалить его с устройства.

Удаление данных на устройстве не удаляет автоматически информацию, которую ранее получил Discord, Яндекс или GitHub. По вопросам такой информации следует обращаться к соответствующему сервису.

## 5. Безопасность и обновления

Обновления загружаются по HTTPS. Перед открытием системного установщика Приложение проверяет размер, SHA-256, идентификатор пакета, версию и соответствие подписи установленному приложению. Установку подтверждает пользователь через Android. Не следует отключать Play Protect ради установки Приложения.

## 6. Изменения документа и связь

Эта политика может обновляться при изменении функций приложения. Актуальная версия размещается по адресу этой страницы.

По вопросам использования приложения и конфиденциальности можно открыть обращение в [публичном репозитории проекта](https://github.com/etozheshrainer/yandex-music-presence-updates/issues). **Не публикуйте в обращениях пароли, токены, персональные данные или приватные логи.**
