# Yandex Music Presence · обновления Android

Публичный репозиторий готовых APK приложения Yandex Music Presence. Основной репозиторий с исходным кодом остаётся закрытым.

## Установочные файлы

- [Последняя версия APK](https://github.com/etozheshrainer/yandex-music-presence-updates/releases/latest)
- [Манифест обновления](latest.json)

Начиная с v0.14 APK подписываются постоянным ключом. Обновления более новых версий доступны через приложение с подтверждением установки Android.
